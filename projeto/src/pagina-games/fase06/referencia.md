3. Assaltos: entrada barulhenta x silenciosa, ferramentas, cofre (combinação x dinamite), cliente que reage,

4. Carros (níveis de segurança, app, rastreador, garagem de 3 vagas, Scooter Bros), NPCs que reagem,
   armas visíveis e limitadas, estilos de luta, relacionamento, mapa, clima, bichos, corpo, atividades, celular.
